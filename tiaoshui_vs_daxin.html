股指期货吃贴水 vs 门票股配置打新

结构化分析 · 自"两策略对比"起的全部推导与修正 · 数据基准日 2026-08-13

本文把"股指期货吃贴水"和"门票股配置打新"两条策略的对比、修正、历史验证、量化测算、当前风险评估与现金处置决策，按逻辑顺序重新整理。所有结论均经历过用户的多轮纠正，文中已标注每一处关键修正点。

一句话总览：同波动层级下，大盘（沪深300/50）门票股打新 ≈ IF 贴水，基本打平；下沉到 IC/IM（中证500/1000）吃贴水明显占优，但伴生小盘高波动。想"贴水+打新"双增强，只能分两池并列或"最小化门票股+期货多头"半替代；期货全替代门票股则拿不到打新额度（硬伤）。当前 IM 指数点位偏高，须降杠杆；要不要现在建，等价于你敢不敢做顶部判断。

一、策略本质与初步对比

1.1 两个策略是什么

  • 股指期货吃贴水：做多 IF/IH/IC/IM（对标本指数），利用期货相对现货的"贴水"（期货比现货便宜），在合约展期时低价移仓、赚取基差收敛的价差。本质是"不承担方向也能赚"的 carry。
  • 门票股配置打新：持有一定市值的 A 股个股（"门票"），换取新股申购额度，靠中签上市涨幅获利。收益 = 打新收益 − 门票股本身波动。

1.3 初步结论与第一次修正

初判"吃贴水更优"（超额 8–13% 是打新的 3–4 倍）。但这一判断很快被两处修正推翻口径，见下文。

二、三个关键修正（让对比变严谨）

2.1 修正①：打新收益率要按持仓规模算

用户纠正：打新收益率跟规模有关，持仓量越小收益率越高；之前按"2 亿机构口径 2.7%"算，把个人打新数压低了。这里指的是沪深，不是北交所。

原理：打新收益分子（中签赚的钱）对个人账户有硬上限——顶格申购额度就那么多，中签金额不随资金增大而变大；分母（持有的门票股市值）却随资金增大而变大。所以：

  • 配到"刚好满足顶格申购"的市值（沪深各约 20–30 万），收益率最高；
  • 再往上加市值，中签金额不变、分母变大，收益率被摊薄——这就是大资金只能拿 2–4% 的原因。
口径纯超额年化
机构（2 亿规模网下 A 类，2025）2.7%（19 年新低）；2026 预测 4.05%
个人（沪深顶格小持仓）4–6%
北交所（2025 累计 / 2026 截至 5-22）2.98% / 1.79%

⚠️ 风险提示：2026 年以来沪深首日破发率高达 26.19%，4–6% 含运气成分，实际到手可能更低。

2.2 修正②：同波动层级对齐，IH/IF 贴水薄

用户纠正：IH/IF 贴水率明显低于 IC/IM；若用沪深300/上证50 的大盘股配置门票股，之前"门票股波动吃掉打新"的说法没考虑波动层级。

核心：贴水率和底层波动是绑定的——IC/IM 贴水高（9%/12%）正因为小盘对冲需求大、波动也大（23%/28%）；IH/IF 贴水薄（~4%，IH 甚至升水），对应大盘波动才 ~16%。公平比法应同层级对齐：

底层层级贴水超额同层打新（沪深）底层波动结论
大盘（沪深300/50）IF ≈4%（IH 甚至升水）4–6%~16%打新 ≈ 贴水，打新略高
中盘（中证500）IC ≈8–9%4–6%~23%贴水明显优
小盘（中证1000）IM ≈10–13%4–6%~28%贴水更优，但波动近 2 倍

结论：选沪深300/50 大盘股做门票，低波底仓 + 4–6% 打新是稳健自洽的"低波动增强"，在这一层级和 IF 贴水打平、还略优（代价是个股选择 + 破发率）。"吃贴水更优"只在下沉到 IC/IM 且愿承小盘波动时成立；拿 IM 的 13% 去碾压沪深300 打新的 6% 不公平，因为 IM 波动是后者的近两倍。

2.3 修正③：组合增强的逻辑硬伤

用户纠正："用 IF/IC 期货替代（或叠加）门票股，吃贴水+打新双增强"无法成立——没有股票持仓，就没法打新。

硬规则：打新额度 = T-2 前 20 个交易日你的日均持股市值换算（每 1 万市值 ≈ 1000 股申购额，沪/深分开）；期货、ETF、基金、债券都不算市值，必须真持个股。所以"替代"和"打新"在同笔本金上互斥。"双增强"真正成立的只有两种结构：

结构做法贴水方向评价
A. 全替代门票股全换期货多头吃贴水(+)❌ 自相矛盾：无持仓→无打新额度
B. 两池并列一笔买门票股打新 + 一笔期货多头吃贴水多头吃贴水(+)✅ 独立本金，代价是总占用翻倍
C. 最小化门票股门票股只留顶格饱和点（沪深各 ~20–30万）+ 余下走期货多头多头吃贴水(+)✅ 最优半替代：保住额度+压个股风险+吃贴水
D. 对冲门票股多 + 期货空对冲空头亏贴水(−)贴水反是成本，隔离的是打新 alpha

3.2 底部附近贴水的变化规律

规律非常戏剧化："先暴扩、后急缩"。

  • 赶底/恐慌时 → 贴水急剧放大（空头套保 panic + 流动性危机）：
    • 2015-16 股灾：IC 年化 −30%，远月极端 −40%
    • 2020.3 COVID：IC −15.4%
    • 2022.9：IM −14.2%
    • 2024.1.17：IM −21.4%（历史最高），2/5 仍 −15.8%
  • 见底/政策干预后 → 贴水快速收敛甚至翻升水（聪明钱 + 汇金进场）：
    • 2018 底：IF 由贴水转升水，IC 从 −10%(8月) 收窄到 −4%(2019.1)
    • 2024.2.6 汇金宣布扩围买中小盘：IM 两周内从 21.4% 砸到 5.1%

⇒ 贴水峰值 ≈ "恐慌底/流动性底"的同步指标（不是领先指标）；它的快速收敛才对应"政策底→市场底"的确认。

提醒：贴水不是免费午餐，是"承担小盘崩溃风险"的补偿。暴跌时吃到的贴水最厚（展期赚最多），但同期指数 beta 在亏。它是缓冲垫，不是方向保护。

4.4 关键洞察

崩盘年贴水反而暴扩 → 你滚贴水吃到的展期收益更高，和指数 beta 是负相关的。所以贴水不是普通的"小红利"，它本质是在别人最恐慌时给你反向输血的缓冲——这也是它十年能持续、且长期跑赢纯多头的根因。但这一切的前提是你没在恐慌底被杠杆强平，所以杠杆预算才是真正的命门。

五、当前 IM 不在低位：风险评估

5.1 两个"低位"维度

"吃贴水"涉及两个独立维度，策略含义完全不同：

  • 贴水率低位 = 贴水薄（像 IF/IH 常年升水）——那时吃贴水不划算。
  • 指数点位低位 = 中证1000 点位低——那时建多头 beta 风险小。

IM 现在贴水 ~11%（正常中枢，不薄），但指数点位 7841 接近 2021 历史高点 8083，距 2024.1 低点 4800 还有 −39% 空间。用户担心的是后者（指数点位高位），这正是核心风险。

5.4 低位入场的优势（对比才显出风险）

  • 若在 4800 恐慌底入场：贴水暴厚到 20%+（2024.1 曾 −21%），且指数已在低位、继续大跌空间小 → 贴水红利更厚 + 安全垫更足，可较激进甚至双赚。
  • 现在 7841 高位：贴水正常、下方还有 −39% 空间 → 必须保守。
安全姿势：① 降杠杆到 1.6–2x（1 手 IM 配 97–100 万现金），别碰满保；② 把 IM 当"替代指数 beta"而非"加杠杆赌博"；③ 留追保弹药，预备指数再跌 30~40% 的保证金，别在恐慌底被迫砍仓。
一句话：贴水策略在高位不失效，但 beta 风险管理比贴水率本身更重要。

六、现金处置：现在吃贴水还是等回落

6.1 本质：择时 vs 不择时

  • 吃贴水 = 不靠方向，横盘也能赚 11% carry（保守 1.6x 下现金回报 +17.8%）。
  • 等回落 = 主动做"顶部判断"——赌高位会跌、且能忍住不建。这不是无风险选项，押的是你的择时能力。

补平点 = 指数跌 −11%：只要不跌超 −11%，现在建都优于"等"；只有当你判断会跌超 −11% 且真能等到，"等"才划算。

6.3 等待的隐性成本

  • 机会成本：若 1 年横盘没回落，每等 1 年净损 ~16%（放弃的贴水 − 货基）。中证1000 自 2024.9 反弹后长期在 6000–7800 晃，未必很快回 4800，空等可能踏空 + 损贴水。
  • 择时陷阱：就算回落，能否忍住不在半路建、真等到最低？低位重建时贴水暴厚（20%+），但你已错过高位期间的贴水。

6.4 实操建议（按确定性分三档）

  1. 坚信会明显回落（−15% 以上）且能忍住 → 等。低位建仓贴水更厚 + 安全垫足，双赚。
  2. 不确定 / 认为可能横盘慢涨 → 别全等，用"保守 1.6x 建底仓 + 留大部分现金等加仓"。现在先吃上 17.8% 贴水红利；真回落到低位，现金加仓吃"厚贴水 + 低安全垫"双赚；不回落也赚了贴水。用低杠杆先上车、用现金保留低位加仓期权。
  3. 若本来就要配门票股打新 → 门票股现在买，不等（打新额度看持仓，早持早有）；只有"纯吃贴水的期货部分"才涉及等不等。

唯一不建议的：满保现在冲（高位爆仓线离当前仅 −15% 空间）。

七、卖 put 等低位：优化方案及其边界

7.1 卖 put 机制与优势

用户提出：用卖出认沽期权（卖 put）替代"空等现金"，把"等回落"和"低位建仓"统一，等待期还有收入。机制：

  • 现金担保卖 MO（中证1000股指期权）的 OTM put，行权价选你真心愿意接货的低位（如 6500，比现价低 17%）。现金做担保、不杠杆。
  • 指数 > K → 权利金落袋（年化约 8–15%，取决于 IV），续卖下一期，继续等——等待期不再零收益。
  • 指数 < K → 被行权，等效以「K − 权利金」低位接货（本例 ≈6338，比现在建便宜 19%），自动衔接 IM 多头滚贴水——此时贴水更厚、安全垫更足，双赚。

这套把"等回落"和"低位吃贴水"彻底 unify，且没有杠杆强平（满保期货的命门被绕开）。

7.2 量化对比（1 年，总盘 150 万；卖 put 假设权利金年化 10%）

你最担心的"跌"情景，卖 put 比现在高位建少亏一大半（−5.3% vs −20.2%、−24.3% vs −45%）——因为它根本没在 7841 高位建多头，直接避开了 7841→6500 那 17% 的下跌，还白收了权利金。

7.3 必须提醒的风险点

  • 亏损不封顶：卖 put 接货后指数可继续跌（如 6500 接了跌到 4800），不是买 put 那种封顶。但无杠杆强平，远优于满保期货。
  • 行权价别选太高：选 7500 这种轻度 OTM，微跌就被行权、接在半山腰，等于没等到真低位。要选你认可的低估位。
  • 踏空上涨：指数暴涨不跌，只收权利金、没吃上涨。但你本就怕高位建了跌，这不算主忧。
  • 权利金厚度看 IV：平静市 IV 低、权利金薄，等待收入少；恐慌时权利金厚但被行权概率也大。

进阶优化：分层卖 put（同时卖 6500/6000/5500 几档行权价的 put，把接货价分散）；接货后转滚贴水（被行权拿到 IM 多头后，后续年份滚贴水 11%+ 才是大头，长期复合收益远超单期权利金）。

7.4 诚实边界：卖 put 不是全局最优

用户质疑：你确定卖 put 更优吗？说不定比吃贴水更差。认错：之前"最优解"说得太满。

本质区别：

  • 吃贴水（现在建 IM 多头，保守 1.6x）= 不依赖方向：横盘 +17.8%、涨 +33.5%、小跌也扛得住，只有跌超 −11% 才输。它是个稳健底仓。
  • 卖 put = 押跌：押对了（指数跌破 K），低位接货还便宜，碾压现在建；押错了（横盘/涨），只收权利金（+10%）踏空，这时比现在建差一大截。
指数位置谁更优理由
< 6500（真跌）卖 put避开高位下跌 + 低位接货，现在建亏 20~45%
6500–7500卖 put 小优 / 持平收权利金 vs 现在建微赚
